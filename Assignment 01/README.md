# Assignment 01

## Matrix Operations

This assignment contains C implementations of basic operations on matrices.

## Tasks

* Matrix addition
* Matrix multiplication
* Matrix inverse
* Matrix transpose

## Files

| File | Description |
| --- | --- |
| `01_matrix_addition.c` | Adds two 3x3 matrices. |
| `02_matrix_multiplication.c` | Multiplies compatible matrices. |
| `03_inverse_of_matrix.c` | Calculates the inverse of a square matrix when possible. |
| `04_transpose_of_matrix.c` | Transposes a matrix by exchanging rows and columns. |

## Compilation

Compile and run a program with GCC:

```powershell
gcc 01_matrix_addition.c -o matrix_addition.exe
.\matrix_addition.exe
```

Replace the source and output names for the other programs.
