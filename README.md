## 📝 Assignment 01

Assignment 01 contains implementations of basic matrix operations in C.

### Tasks

* [x] Matrix Addition
* [x] Matrix Multiplication
* [x] Matrix Inverse
* [x] Matrix Transpose

### Matrix Addition

Adds two matrices of compatible dimensions.

```text
C = A + B
```

### Matrix Multiplication

Multiplies two compatible matrices.

```text
C = A × B
```

### Matrix Inverse

Calculates the inverse of a square matrix when its determinant is non-zero.

```text
A⁻¹ = (1 / det(A)) × adj(A)
```

### Matrix Transpose

Converts rows into columns and columns into rows.

```text
Aᵀ[i][j] = A[j][i]
```
