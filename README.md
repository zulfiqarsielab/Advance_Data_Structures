## Course Overview

This repository contains laboratory assignments and practice programs covering fundamental and advanced data structures, especially linked lists, stacks, and matrix operations.

## Repository Structure

- **Assignment 01** – Matrix operations such as addition, multiplication, transpose, and inverse
- **Assignment 02** – Stack and queue implementation exercises
- **Assignment 03** – Single and double linked list implementations
- **Lectures** – Course lecture materials

## Current Assignment Coverage

### Assignment 03

The linked list assignment includes:

- Single linked list with insert, update, delete, retrieve, and print functions
- Double linked list with insert, update, delete, retrieve, and print functions
- Dynamic memory management using pointers
- Duplicate ID prevention and validation checks
